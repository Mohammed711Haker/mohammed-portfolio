# Mohammed Humaidhah — Interactive Portfolio

Next.js 16 · React 19 · TypeScript · Tailwind 4 (no extra dependencies).

## Features
- Live network-canvas background (reacts to mouse, click to burst)
- Typing role banner, 3D-tilt photo with orbiting tech chips (click → opens the skill)
- Arabic (RTL) / English toggle and dark / light theme (saved in the browser)
- Command palette (Ctrl/⌘ + K) and a fully interactive terminal (`help`, `neofetch`, `sudo hire-me`…)
- Skills explorer, expandable journey timeline, filterable 3D project cards
- Project demos: Smart Parking simulator (ESP32), VisionCheck "E" test, Debian/Nginx replay
- Live GitHub repos + language mix from the public API (falls back to a snapshot)
- Gallery with filters + lightbox (keyboard / swipe), contact form → mailto, copy-email
- Easter egg: Konami code 😉

## Edit your content
All text (EN + AR), skills, projects and captions live in `lib/data.ts`.

## Run
```bash
npm install
npm run dev
```
